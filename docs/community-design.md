# 피드 설계

상태: Q1~Q14 및 전체 설계 승인 후 구현 완료.

## 확정된 범위

- 상단 메뉴에 피드를 추가한다.
- 피드는 로그인한 사용자에게 제공한다. 메뉴 클릭과 주소 직접 접근 모두 비로그인 시 로그인 페이지로 이동한다.
- 피드 진입을 위해 로그인한 사용자는 로그인 후 피드로 복귀한다.
- 팔로잉과 인기 탭을 분리하고 팔로잉을 기본 탭으로 제공한다.
- 기존 게임 리뷰를 조회하고 기존 리뷰 상호작용을 활용하는 범위로 한정한다.
- 최초 피드 구현 범위에는 자유게시판, 일지, 새로운 댓글 기능을 포함하지 않았다. 후속 댓글 기능은 [리뷰 댓글 설계](review-comments-design.md)에서 별도로 결정한다.
- 기존 게임 상세 등에서의 리뷰 공개 정책은 유지한다.
- 인기 탭은 최근 7일에 작성된 리뷰 중 누적 좋아요가 1개 이상인 리뷰를 누적 좋아요 내림차순으로 보여준다. 동률은 최신 작성순이다. 최근 7일 동안 받은 좋아요를 집계하는 방식은 아니다.
- 팔로잉과 인기 탭 모두 본문이 있는 리뷰만 표시한다. 별점만 있는 평가는 제외한다.
- 팔로잉 피드는 현재 팔로우 관계를 기준으로 팔로우 이전에 작성된 리뷰도 포함한다. 최초 작성일 최신순이며 수정으로 순서가 올라가지 않는다.
- 언팔로우한 사용자의 리뷰는 다음 조회부터 제외한다.
- 팔로잉이 없으면 “팔로우한 사람이 없습니다”, 팔로잉은 있으나 리뷰가 없으면 “아직 등록된 리뷰가 없습니다”를 표시한다. 인기 탭으로 이동하는 “인기 리뷰 둘러보기” 버튼을 제공한다.
- 피드 진입에서 시작된 로그인에서는 관리자도 피드로 복귀한다. 온보딩 대상자는 온보딩 완료 또는 건너뛰기 후 피드로 복귀한다. 다른 로그인 흐름은 유지한다.

## 목록과 카드 동작

- 팔로잉은 20개씩 “더 보기”로 추가 조회한다. 인기는 상위 20개까지 제공한다.
- 피드 인기 탭은 “최근 7일 인기 리뷰”라고 명시한다. 조건에 맞는 리뷰가 없으면 빈 상태를 표시하며 이전 기간 리뷰로 대체하지 않는다.
- 기존 홈의 인기 리뷰는 전체 기간 기준을 유지한다.
- 카드에서 작성자 프로필과 게임 상세로 이동하고, 좋아요를 토글하며, 긴 본문을 펼칠 수 있다.
- 팔로잉·인기 리뷰 카드는 게임 상세의 플레이어 리뷰와 배경·테두리·여백, 작성자와 별점 배치, 좋아요 디자인을 맞춘다. 카드 내부의 작성자·좋아요·댓글 영역 사이 구분선은 표시하지 않고, 좋아요는 왼쪽으로 정렬한다. 게임 표지·제목 링크는 유지하고 좋아요 옆 “게임 상세에서 보기” 링크는 제거한다.
- 스포일러 리뷰의 본문은 사용자가 공개 버튼을 누르기 전까지 가린다.
- 별점 옆에 작성자의 현재 플레이 상태를 게임 상세 플레이어 리뷰와 같은 기준으로 표시한다. 플레이 중, 완료, 중단, 보류, 예정, 위시리스트 순으로 우선하며 상태가 없으면 표시하지 않는다.
- 수정·삭제·신고는 기존 화면에서 처리한다.
- 선택한 탭을 주소에 반영해 새로고침과 로그인 후 복귀 시 유지한다. 기본 진입 탭은 팔로잉이다.
- 조회 실패는 빈 목록과 구분하고 “다시 시도”를 제공한다. 추가 조회 실패 시 기존 목록은 유지한다.
- 최근 7일은 조회 시점부터 직전 168시간이다.
- 인기 순위는 다시 조회할 때 갱신한다. 좋아요 조작 직후에는 숫자만 갱신하고 카드 순서를 즉시 바꾸지 않는다.

## 구현 및 검증

- 페이지: `/community`, 인기 탭: `/community?tab=popular`.
- 로그인 필수 API: `GET /api/v1/community/reviews/following?page=0`, `GET /api/v1/community/reviews/popular`.
- 기존 테이블과 좋아요 API를 재사용한다. 스키마 변경은 없다.
- 동일 작성 시각에는 리뷰 ID 내림차순으로 순서를 고정한다.
- 백엔드 통합 테스트는 인증 제한, 팔로우/언팔로우, 본문·공개 상태 필터, 좋아요 여부와 0개 집계, 20개 페이지, 168시간 경계, 인기 최대 20개를 검증한다.
- 기존 인기 리뷰 컨트롤러·저장소 회귀 테스트를 함께 실행한다.
- 브라우저 검증은 모의 API 응답으로 로그인·관리자·온보딩 복귀, 탭 유지, 스포일러, 본문 펼치기, 좋아요, 추가 조회·새로고침 재시도, 빈 상태, 세션 만료와 모바일 너비를 확인한다.
- 프론트 프로덕션 빌드와 피드 및 로그인 변경 코드의 린트를 확인한다. 온보딩 파일에는 기존 `set-state-in-effect` 오류와 이미지 경고가 있어 전체 파일 린트는 통과하지 않는다.

## 확인된 기존 동작

아래는 설계 결정이 아니라 2026-10-20 코드 조사 결과다.

- 기존 인기 리뷰는 전체 기간 누적 좋아요 순이며, 본문과 좋아요가 있는 공개 가능한 리뷰를 대상으로 한다. 기간 필터와 페이지네이션은 없다.
- 로그인은 next 쿼리로 복귀 경로를 처리하지만 관리자와 온보딩 대상자는 별도 경로로 이동한다. 온보딩 완료 시에는 홈으로 이동한다.
- 팔로우 관계는 존재하지만 팔로잉 리뷰를 통합 조회하는 API는 추가해야 한다.
