# 라이브러리 포함 여부 보정 (#187)

현재 데이터베이스를 확인한 후 `preview.sql`로 변경 대상과 전체 건수를 조회한다. 좋아요는 포함 기준에서 제외하며, 시간 0도 기록이 존재하므로 포함한다.

실제 반영 전에는 대상 결과를 사용자와 확인하고 백업한다. 수정된 애플리케이션 배포 후 쓰기 요청을 중단한 유지보수 시간에 실행한다. `repair.sql`은 기본적으로 트랜잭션을 롤백한다. 승인된 반영에 한해서 마지막 `ROLLBACK`을 `COMMIT`으로 변경한다. 동일 스크립트를 재실행해도 값이 일치하는 행은 변경하지 않는다.

보정은 UserGame 및 리뷰 행을 삭제하지 않는다. 인생 게임 정리는 별도 기능의 보정 스크립트에서 수행한다. 운영 DB에는 자동 실행하지 않는다.
